# NIVET ROYALE

[Play on GitHub Pages](https://jikjikla.github.io/anothergptonetouse/)

Chapter 1 Season 5 browser battle royale on a 600-meter island with Tilted Towers, Retail Row and Lazy Links. Open Change Mode for Solo, Duos, Trios, Squads or 50 v 50, with offline bot teammates and opponents. TE and VIN start on opposite buses in 50 v 50. Select a location in Practice to learn the island or drive a shopping cart.

On Chromebooks, open the game in Chrome with WebGL2 and select Graphics → Auto. It starts at full 3D canvas resolution and adapts when a lower resolution improves frame time. The HUD, original texture data, and nearby details are preserved.

WASD moves. Mouse looks. Left click fires, uses the selected heal or places a build. Right click aims. Sprint by Default is enabled and Shift jogs while held. Ctrl crouches and Space jumps, drops or deploys the glider. E searches, picks up or enters a cart. In a cart, W pushes, S brakes, A and D steer, Space kicks, C changes seat and E exits. Shift+E swaps loot and X drops the selected item. R reloads and 1–6 select slots. Q toggles building and F1–F4 select wall, floor, ramp and cone. F edits, 1–9 toggle wall tiles and Enter confirms. Shift+F resets the edit and V changes material. Escape pauses. If mouse capture is unavailable, middle drag or Alt+drag looks around.

The island uses the supplied location meshes and textures, with connected roads and traversable interiors. The environment files total 131.0 MB before HTTP compression. Additional outfits load on selection. Matches run offline. [Credits](CREDITS.md).

The title, Play lobby, mode picker and Locker follow the supplied Chapter 1 references. The outfit portraits and animated previews use the game models. The sky changes from blue cloud layers to a luminous storm wall, and the original Tilted treasure chest uses its source metal and roughness masks. In play, the camera uses an 80-degree horizontal field of view, both palms track weapon grips, and the island's north connector clears the factory wall. [Season 5 reference](https://www.fortnite.com/patch-notes/v5-0) · [Shopping cart reference](https://www.fortnite.com/patch-notes/v4-3)

The harvesting update makes more than 5,700 building pieces, vehicles, props, trees, rocks, and shrubs breakable. Use the pickaxe to collect wood, stone, or metal and aim for the blue weak point. The update also restores missing outfit material assignments, pavement textures, car paint, grass cutouts, and rock color.

This directory contains the prebuilt client and its required runtime files. It requires no server, accounts or package installation. The editable Vite project and source archive are maintained separately.
