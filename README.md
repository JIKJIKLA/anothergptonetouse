# NIVET ROYALE

[Play on GitHub Pages](https://jikjikla.github.io/anothergptonetouse/)

Solo browser battle royale on a 600-meter island with Tilted Towers, Retail Row and Lazy Links. Eleven bots drop along the bus route. Choose Easy, Normal or Hard in Settings, or select a location in Practice. Keyboard and mouse are required.

WASD moves. Mouse looks. Left click fires, uses the selected heal or places a build. Right click aims. Shift sprints, Ctrl crouches and Space jumps, drops or deploys the glider. E searches or picks up, Shift+E swaps and X drops the selected item. R reloads and 1–6 select slots. Q toggles building and F1–F4 select wall, floor, ramp and cone. F edits, 1–9 toggle wall tiles and Enter confirms. Shift+F resets the edit and V changes material. Escape pauses. If mouse capture is unavailable, middle drag or Alt+drag looks around.

The island uses the supplied location meshes and textures, with connected roads and traversable interiors. Selected roof and wall panels can be broken. Initial environment data is about 128 MB, and additional outfits load on selection. Matches run offline. [Credits](CREDITS.md).

The three-POI release adds striped fairways and sand bunkers at Lazy Links, restores the clubhouse shingles, and corrects the terrain below the Retail Row Taco storefront. The assault rifle, pump and SMG have distinct handling, and the HUD shows when the reticle has recovered its accuracy.

This directory contains the prebuilt client and its required runtime files. It requires no server, accounts or package installation. The editable Vite project and source archive are maintained separately.
